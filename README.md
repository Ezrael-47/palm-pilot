What is a Palm Pilot?
The Palm Pilot was a pioneering personal digital assistant (PDA) released in 1997 by Palm Computing. It featured a monochrome touchscreen, a stylus-based handwriting recognition system called Graffiti, and ran basic apps like contacts, calendar, and notes. It was the iPhone of its era — over 1 million units sold in its first 18 months. The device defined mobile productivity before smartphones existed, making digital organization portable for the first time.

About This Project
This is a nostalgic web simulator that recreates the look and feel of a classic Palm Pilot device, but with a modern twist — it's dedicated entirely to MrBeast (Jimmy Donaldson), the world's most-subscribed individual YouTuber.

Built with pure HTML, CSS, and JavaScript (no frameworks), this project serves as both a retro UI experiment and a fan information hub. It runs entirely in the browser and is mobile-responsive.
